# Minimum Spanning Tree (MST) Problem

Problem minimalnego drzewa rozpinającego polega na znalezieniu w grafie podzbioru krawędzi,
które łączą wszystkie węzły bez tworzenia cykli, tak by suma kosztów tych krawędzi była jak najmniejsza.
Model ten jako MIP wymaga ograniczeń eliminacji podcykli (subtour elimination constraints).
Wykorzystuje się do tego wszystkie podzbiory węzłów (generowane przez zbiór potęgowy).
